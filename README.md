A bilingual (English / Ukrainian) one-page resume for a Frontend Developer, with light and dark themes and eight colour palettes. It is built with plain HTML, CSS and JavaScript, with no frameworks and no runtime dependencies. A small Node.js script generates static pages for each language from a single data file, `data/resume.json`, and the site is published on GitHub Pages at https://chizhik8.github.io/resume/.

Run locally with `npm run dev` (http://localhost:8080/resume/), build with `npm run build`, test with `npm test`.
